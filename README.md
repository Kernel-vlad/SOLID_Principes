# Codeforces 486A - Calculating Function 🧮

Ця задача проста, але вона вчить оптимізації коду, щоб він працював швидко.

## 📝 Опис задачі
Нам дана функція: 
`f(n) = -1 + 2 - 3 + 4 - 5 + ... + ((-1)^n * n)`

Треба знайти значення цієї функції для заданого числа **n**.

## 💡 Логіка рішення
Якщо вирішувати задачу через цикл `for`, програма буде працювати занадто довго для великих чисел (наприклад, $10^{15}$). Тому ми використовуємо просту математику:

1. Якщо **n** — парне (even), то результат завжди дорівнює **n / 2**.
2. Якщо **n** — непарне (odd), то результат завжди дорівнює **-(n + 1) / 2**.
